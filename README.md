# PoissonUtils 

`PoissonUtils` is a collection of R tools and scripts designed for statistical analysis, modeling, and manipulation of count data following a **Poisson distribution**.

* **Model Fitting:** Parameter estimation and hypothesis testing for count data.
* **Graphical Visualizations:** Plotting theoretical vs. observed distributions.
* **Applied Case Studies:** Practical R scripts for real-world analyses.

##  Repository Structure

* `ProjetLoiDePoissonR/` : Main scripts and documents regarding the Poisson distribution.
* `AccidentPoisson/` : Practical case study on accident data.
* `aggregation.R` / `poisson.R` / `detect.R` : R scripts for exercises and practical applications.
* `*.pptx` : Analysis reports and related presentations.
